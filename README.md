# คุ้มไหม? — เทียบราคาต่อหน่วย

เว็บแอป (PWA) ไฟล์เดียว ใช้ได้ทั้ง Android, iOS และเว็บ ติดตั้งลงหน้าจอโฮมได้ และใช้งานออฟไลน์ได้

## ความสามารถ
- เทียบ 2–6 รายการ คำนวณทันทีที่พิมพ์ (ไม่ต้องกดปุ่ม)
- ราคา × จำนวนชิ้นในแพ็ค × ขนาดต่อชิ้น (ชิ้น / g / kg / ml / L) แปลงหน่วยให้อัตโนมัติ
- ไฮไลต์อันที่คุ้มสุด, บอก % ที่แพงกว่า, และเงินที่ประหยัดได้
- เตือนเมื่อเทียบหน่วยคนละกลุ่ม (น้ำหนัก vs ปริมาตร)
- จำค่าที่กรอกไว้ในเครื่อง

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (HTML + CSS + JS) |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งเป็นแอป |
| `sw.js` | service worker สำหรับออฟไลน์ |
| `icons/` | ไอคอนแอป |
| `serve.js` | เซิร์ฟเวอร์ทดสอบในเครื่อง |

## ทดสอบในเครื่อง
```bash
node serve.js
```
เปิด http://localhost:5173

## เอาขึ้นออนไลน์ (ฟรี)
อัปโหลดทั้งโฟลเดอร์ (ยกเว้น `serve.js`, `.claude/`) ไปที่ GitHub Pages, Netlify หรือ Cloudflare Pages — ต้องเป็น **https** ถึงจะติดตั้งเป็นแอปได้

## ติดตั้งบนมือถือ
- **iPhone (Safari):** ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android (Chrome):** เมนู ⋮ → "ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก"

## ถ้าอยากลง App Store / Play Store
ห่อด้วย [Capacitor](https://capacitorjs.com/) ได้โดยไม่ต้องแก้โค้ด (iOS ต้องใช้ Mac + Apple Developer account $99/ปี, Play Store ค่าสมัคร $25 ครั้งเดียว — ราคาอาจเปลี่ยน ควรเช็คอีกครั้ง)

เมื่อแก้ไฟล์แล้ว ให้เปลี่ยน `VERSION` ใน `sw.js` ด้วย
